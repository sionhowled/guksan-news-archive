# 국산 — 뉴스·사례 지도

추가 패키지 설치 없이 동작하는 정적 사이트입니다. 선별한 31개 사례를 수록합니다. 마지막 사례 추가: 2026-09-24. 각 사례의 확인일은 상세 보기에 표시합니다.

- `npm run dev`: 로컬 미리보기
- `npm run build`: 데이터 검증 및 dist 출력
- `data.js`: 사례 내용과 원문 출처

확인 상태는 위험 등급이 아닙니다. 원료 사용, 통관 차단, 국내 회수, 산업 피해 판정, 후속 확인을 구분합니다. 배터리 보고서는 발표 월만 확인되어 표시에서는 일자를 생략합니다.

뉴스 상세 하단에서 삭제할 수 있습니다. 로컬 서버가 data.js에 저장하며 .news-trash에 삭제 기록을 보관합니다. 자동 조사 시 이 폴더의 id 및 원문 URL과 일치하는 뉴스를 다시 추가하지 마세요. 정적 외부 호스팅에서는 삭제 API를 지원하지 않습니다.
